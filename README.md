# SISTEMA-EXPERTO-ACTS-CULTURALES-IPN
Proyecto para Primer Parcial - Paradigmas de la Programación 

Elaborado por:
Arcia Palma Carlos Fernando
García González Sophia

El sistema busca ayudar a jóvenes estudiantes del IPN a encontrar alguna actividad cultural disponible y congruente con sus intereses y aptitudes. También informara de la oportunidad de recibir becas o apoyos económicos de ser posible habiendo elegido una actividad.
